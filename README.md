# Tablemate

A small, browser-only poker session ledger. Add players, record bank or player-to-player buy-ins, undo entries, cash out players and see a simplified settlement plan.

## Run locally

Open `index.html` in a modern browser. Session data is stored in that browser's local storage and can be exported as JSON from the page.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys this site to GitHub Pages whenever changes are pushed to `main`.

In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The public site will be available at:

`https://sanjeevkrishnaa.github.io/tablemate-poker-night/`
